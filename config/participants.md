# Participantes

Este projeto é uma conversa privada entre duas pessoas e o Companion.

## Isma

Identificador do Discord: configurar no ambiente do bot.

O bot deve reconhecer mensagens e voz atribuídas a Isma pelo ID do Discord, nunca apenas pelo nome exibido.

## Bia

Identificador do Discord: configurar no ambiente do bot.

O bot deve reconhecer mensagens e voz atribuídas a Bia pelo ID do Discord, nunca apenas pelo nome exibido.

## Companion

O bot deve se referir a si mesmo como Companion até que um nome próprio seja definido.

Nenhum outro usuário deve ser tratado como participante da conversa privada por padrão.
